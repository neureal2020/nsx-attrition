# Program 15: Cooper University Hospital / CMSRU Neurosurgery (formerly the PCOM Neurosurgery Residency)

## Program history
- ACGME ID 1604100136 has state code 41, which is Pennsylvania. The ID belongs to the **Philadelphia College of Osteopathic Medicine (PCOM) neurosurgery residency**. That program was AOA-approved (35th year in 2017), ran across several sites (Cooper, Abington, Geisinger, Geisinger Wyoming Valley, Reading) under PD Steven Yocom DO, had 12 positions, and was ACGME-accredited by 2019. Sponsorship moved to Cooper in 2022. The Cooper alumni page lists PCOM-era graduates from 2021 on, so this is one continuous program.
- AOA-era classes finished at **PGY-6** (the page lists PGY2-6, and interns were not listed in 2014-15). The 2014 entrants onward did 7 years (PGY-7 in 2020-21).
- Entry class sizes: 2014 = 3; 2015, 2016, 2017 = 2 each; 2018 to 2025 = 1 each; 2026 = 2. Current complement is 1 per year (Cooper "one PGY1 position each year").
- This is not a new program, so `first_class_year` is null.
